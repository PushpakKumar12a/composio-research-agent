Verification Pipeline

Independent agent re-researches 20 sampled apps, does direct page fetching via httpx + BeautifulSoup, and compares field-by-field.

1. PARSE     100_apps.json → List[AppEntry]
             ↓
2. SEARCH    For each app → Dynamic Tavily developer docs query
             Batched with ThreadPoolExecutor parallel workers
             ↓
3. ANALYZE   Search results → GPT-4o → Structured JSON per app
             System prompt enforces schema: auth, access, API, buildability
             ↓
4. CHECKPOINT Save after each batch for crash recovery
             ↓
5. VERIFY    Sample 20 apps (2/category) → fresh search + page fetch
             Compare field-by-field → accuracy metrics
             ↓
6. GENERATE  results.json + verified_results.json → Jinja2 template rendering
             → Self-contained HTML with Chart.js, sortable table
